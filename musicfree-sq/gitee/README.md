# MusicFree 音源插件 - 音乐搜索神器

## 简介
多平台聚合音乐搜索（网易云/QQ/酷狗/酷我/百度/一听/咪咕/荔枝/蜻蜓/喜马拉雅/5sing），基于 music.lmb520.cn 后端，免登录。

## 安装方式
### 方式一：订阅源安装（推荐）
将以下 URL 添加到 MusicFree 订阅源：
https://gitee.com/koujiao/musicfree-tianpeng/raw/master/musicfree-sq/gitee/sq.js

### 方式二：本地安装
下载 `sq.js` 文件，在 MusicFree 中手动导入。
