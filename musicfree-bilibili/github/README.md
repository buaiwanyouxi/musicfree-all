# MusicFree 音源插件 - 哔哩哔哩(Bilibili)

## 简介
B站音频/视频音源，支持登录态(SESSDATA)与匿名双路取链。

## 安装方式
### 方式一：订阅源安装（推荐）
将以下 URL 添加到 MusicFree 订阅源：
https://raw.githubusercontent.com/buaiwanyouxi/musicfree-all/main/musicfree-bilibili/github/bilibili.js

### 方式二：本地安装
下载 `bilibili.js` 文件，在 MusicFree 中手动导入。
