# MusicFree 音源插件 - 汽水音乐

## 简介
汽水音乐音源（抖音系接口，双域名互备）。

## 安装方式
### 方式一：订阅源安装（推荐）
将以下 URL 添加到 MusicFree 订阅源：
https://raw.githubusercontent.com/buaiwanyouxi/musicfree-all/main/musicfree-qs/github/qs.js

### 方式二：本地安装
下载 `qs.js` 文件，在 MusicFree 中手动导入。
