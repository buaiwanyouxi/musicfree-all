# MusicFree 音源插件 - 布谷音乐

## 简介
酷我音乐镜像+直连音源，支持跨源映射（网易云/QQ/酷狗→酷我）。

## 安装方式
### 方式一：订阅源安装（推荐）
将以下 URL 添加到 MusicFree 订阅源：
https://raw.githubusercontent.com/buaiwanyouxi/musicfree-all/main/musicfree-buguyy/github/buguyy.js

### 方式二：本地安装
下载 `buguyy.js` 文件，在 MusicFree 中手动导入。
