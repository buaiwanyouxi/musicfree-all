# MusicFree 音源插件 - QQ音乐

## 简介
QQ音乐音源，官方 CgiGetVkey + GD音乐台/MyFreeMP3/aax/mvmp3/qeecc 六层分层竞速取链；音乐搜索神器(music.lmb520.cn) 与 sq.js 同源、降为最后兜底，独立备用源为 gd/myf/aax/mv/qe 共 5 个（含播放链缓存与预取）。

## 安装方式
### 方式一：订阅源安装（推荐）
将以下 URL 添加到 MusicFree 订阅源：
https://raw.githubusercontent.com/buaiwanyouxi/musicfree-all/main/musicfree-qq/github/qq.js

### 方式二：本地安装
下载 `qq.js` 文件，在 MusicFree 中手动导入。
