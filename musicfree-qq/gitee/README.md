# MusicFree 音源插件 - QQ音乐

## 简介
QQ音乐音源，官方 CgiGetVkey + 音乐搜索神器/GD音乐台/MyFreeMP3/aax/mvmp3/qeecc 七层分层竞速取链（含播放链缓存与预取）。

## 安装方式
### 方式一：订阅源安装（推荐）
将以下 URL 添加到 MusicFree 订阅源：
https://gitee.com/koujiao/musicfree-tianpeng/raw/master/musicfree-qq/gitee/qq.js

### 方式二：本地安装
下载 `qq.js` 文件，在 MusicFree 中手动导入。
