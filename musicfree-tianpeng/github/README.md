# MusicFree 音源插件 - 天蓬聚合

## 简介
聚合酷狗/酷我/QQ/汽水/网易云/B站 六平台音源的路由聚合插件。

## 安装方式
### 方式一：订阅源安装（推荐）
将以下 URL 添加到 MusicFree 订阅源：
https://raw.githubusercontent.com/buaiwanyouxi/musicfree-all/main/musicfree-tianpeng/github/tianpengjh.js

### 方式二：本地安装
下载 `tianpengjh.js` 文件，在 MusicFree 中手动导入。
