# MusicFree 音源插件 - 网易云音乐

## 简介
网易云音乐音源，官方明文接口 + 无名音乐网/歌曲宝/布谷音乐三层备用；下沉「歌名+歌手」双因子身份校验，无安全候选拒绝错播。

## 安装方式
### 方式一：订阅源安装（推荐）
将以下 URL 添加到 MusicFree 订阅源：
https://raw.githubusercontent.com/buaiwanyouxi/musicfree-all/main/musicfree-wy/github/wy.js

### 方式二：本地安装
下载 `wy.js` 文件，在 MusicFree 中手动导入。
