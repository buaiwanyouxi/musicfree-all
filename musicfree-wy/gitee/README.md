# MusicFree 音源插件 - 网易云音乐

## 简介
网易云音乐音源，官方明文接口 + 无名音乐网/歌曲宝/布谷音乐三层备用；下沉「歌名+歌手」双因子身份校验，无安全候选拒绝错播；v0.1.3 修复「推荐歌单/精品歌单只能获取前 10 首」——/playlist/detail 显式传 limit(1000) 使 tracks 直接回全量，不再被接口默认 ~10 首截断。

## 安装方式
### 方式一：订阅源安装（推荐）
将以下 URL 添加到 MusicFree 订阅源：
https://gitee.com/koujiao/musicfree-tianpeng/raw/master/musicfree-wy/gitee/wy.js

### 方式二：本地安装
下载 `wy.js` 文件，在 MusicFree 中手动导入。
