# 酷狗音源插件（kg.js）使用说明

> **平台**：酷狗 ｜ **版本**：v0.0.9 ｜ **作者**：tianpeng
> **适配**：[MusicFree](https://github.com/maotoumao/MusicFree) 桌面端 / 移动端

---

## 一、插件定位

将「酷狗」作为一个独立音源接入 MusicFree，重点解决**取链可用性**问题：

- 酷狗官方取链接口当前大量返回空 `play_url`（接口层面已失效），因此仅作为第一优先尝试；
- 首选备用音源 **无名音乐网（mvmp3.com）**：取链质量高，其「我不是人机」为人机软验证，插件**自动**完成验证并缓存约 50 分钟，无需手动操作；
- 次选备用音源 **歌曲宝（gequbao.com）**：无需验证，作为 mvmp3 自动过验证偶发失败时的兜底。

**取链顺序**：`酷狗官方 → 无名音乐网 mvmp3 → 歌曲宝 gequbao`，任一层成功即用，尽量保证「有歌可播」。

## 二、支持功能

| 功能 | 方法 | 说明 |
|------|------|------|
| 搜索 | `search` | 仅单曲（music），走 `mobilecdn.kugou.com` 接口 |
| 播放取链 | `getMediaSource` | 三层兜底（见上） |
| 歌词 | `getLyric` | 官方 + 备用源兜底 |
| 歌单导入 | `importMusicSheet` | 粘贴酷狗歌单链接导入 |
| 歌单详情 | `getMusicSheetInfo` | 点进歌单后的歌曲列表 |
| 排行榜 | `getTopLists` / `getTopListDetail` | 酷狗官方 55 个榜单（飙升/新歌/TOP500/各语种流派） |
| 热门榜单 | `getTopLists` | 精选「历史收藏最多」等高热度榜 |
| 热门歌单广场 | `getRecommendSheetTags` / `getRecommendSheetsByTag` | 按风格/场景/语种/心情分类浏览酷狗歌单 |

### 歌单导入格式

支持粘贴酷狗歌单链接，例如：

```
https://www.kugou.com/songlist/gcid_3zjy761gz1maz03e/
https://www.kugou.com/songlist/123456.html
```

### 排行榜 / 热门歌单

- 「排行榜」按 **热歌 / 地区 / 特色 / 全球 / 曲风** 分层归组；
- 「热门榜单」精选历史收藏最多、历史播放最多、今日推荐等高热度榜；
- 「歌单」Tab 提供酷狗歌单广场，标签目录为内置静态分类（始终可用），点击标签后按关键词调用酷狗歌单搜索接口返回结果；
- 歌单详情/导入取歌使用 `mobilecdn` 的 `special/song` JSON 接口（v0.0.9 修复点进歌单歌曲空白问题）。

## 三、所需配置（可选）

| 配置项 key | 名称 | 必填 | 说明 |
|------------|------|------|------|
| `mvmp3_cookie` | 无名音乐网 Cookie (PHPSESSID) | 否 | 通常**无需填写**。插件会自动完成人机验证并缓存 50 分钟。仅当你想固定使用自己浏览器会话时才填：仅填 `PHPSESSID` 的值或完整 `PHPSESSID=值` 均可。留空即可全自动使用高质量音源。 |

> 酷狗官方浏览（搜索/榜单/歌单）**无需任何 Cookie**。

## 四、安装方法

MusicFree →「设置」→「插件设置」→「从网络安装插件」→ 填入本插件源码直链（gitee 发布后提供）。

也可本地「从文件安装」选择 `kg.js`。

## 五、已知限制

1. **酷狗官方取链失效**：官方 `play/getdata` 当前大量返回空链，故实际播放多依赖 mvmp3 / gequbao 备用源；这是上游接口变动，非插件缺陷。
2. **CDN Referer 限制（实测坑）**：kuwo CDN 的音频直链**不能带 Referer**，带 mvmp3/gequbao 站 Referer 会 403；因此备用源返回的媒体只给 `{url}`、不带 headers，酷狗 CDN 才需要 kugou Referer。插件已按此处理，用户无需关心。
3. **mvmp3 偶发验证升级**：若该站临时升级人机验证导致自动过验证失败，可在 `mvmp3_cookie` 填入自己的 `PHPSESSID` 跳过；歌曲宝会自动兜底。

## 六、常见问题

**Q：为什么有的歌点开要等一会儿才出声？**
A：酷狗官方取链失败后，插件会自动切换到 mvmp3 / gequbao 搜索匹配并取链，多一层网络往返，属正常现象。

**Q：热门歌单里点进标签没反应？**
A：标签目录为内置静态分类始终可用；若某标签下酷狗返回空，多为该关键词无结果，换标签即可。
