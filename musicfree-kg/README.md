# MusicFree 音源插件 - 酷狗音乐

> **版本**：v0.1.15 ｜ **作者**：tianpeng + 优化(下沉 qq.js v0.1.8 三态校验)

## 简介
酷狗音乐音源，取链链序：酷狗官方(软熔断) → 无名音乐网(mvmp3)② → 歌曲宝(gequbao)③ → 酷我系5(歌曲海/歌曲客/凤梨/溜声/无忧)④-⑧ → 网易系4(GD音乐台/MyFreeMP3/我要下歌/音乐搜索神器)⑨-⑫ → 独立站2(小蜜蜂/音微)⑬ → AAX音乐网(aax.cx)⑭末位。全链路下沉「歌名+歌手」双因子身份校验，无安全候选拒绝错播；命中备选源打 `X-Kg-Backup` 溯源头；v0.1.2 删除官方直链 HEAD 探测，回归首播速度。

## 安装方式
### 方式一：订阅源安装（推荐）
将以下 URL 添加到 MusicFree 订阅源：
https://raw.githubusercontent.com/buaiwanyouxi/musicfree-all/main/musicfree-kg/github/kg.js

### 方式二：本地安装
下载 `kg.js` 文件，在 MusicFree 中手动导入。
