# MusicFree 音源插件 - 酷狗音乐

## 简介
酷狗音乐音源，官方直链取链 + 无名音乐网/歌曲宝/AAX音乐网三层备用（共四层取链）；含三态身份校验防错播、官方取链软熔断、取链质量打分。

## 安装方式
### 方式一：订阅源安装（推荐）
将以下 URL 添加到 MusicFree 订阅源：
https://cdn.jsdelivr.net/gh/buaiwanyouxi/musicfree-all@v0.1.0/musicfree-kg/kg.js

### 方式二：本地安装
下载 `kg.js` 文件，在 MusicFree 中手动导入。
