# MusicFree 音源插件 - 酷狗音乐

## 简介
酷狗音乐音源，官方直链 + 无名音乐网(mvmp3)/歌曲宝(gequbao)/AAX音乐网(aax.cx) 四层兜底取链；下沉「歌名+歌手」双因子身份校验，无安全候选拒绝错播；v0.1.2 删除官方直链 HEAD 探测，回归首播速度。

## 安装方式
### 方式一：订阅源安装（推荐）
将以下 URL 添加到 MusicFree 订阅源：
https://gitee.com/koujiao/musicfree-tianpeng/raw/master/musicfree-kg/gitee/kg.js

### 方式二：本地安装
下载 `kg.js` 文件，在 MusicFree 中手动导入。
