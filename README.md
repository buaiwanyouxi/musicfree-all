# 聚合音乐 MusicFree 插件（musicfree-all）

将三个独立 MusicFree 插件合并为**一个插件**：

| 源 | 站点 | 数据源 | id 前缀 |
|----|------|--------|---------|
| 咪咕音乐 | music.migu.cn | 咪咕官方接口 | `mg:` |
| 我要下歌 | xiage.yiwuku.com | 酷我 CDN（站点内联音源） | `xi:` |
| 布谷音乐 | buguyy.top | 酷我音乐 | `bg:` |

合并原理：每个媒体项 / 榜单项的 `id` 都打上源前缀（`mg:` / `xi:` / `bg:`），
由统一入口按前缀路由到对应子插件的实现，子实现内部使用「去掉前缀后的真实 id」。

## 功能

- ✅ 搜索（歌曲名 / 歌手）：三源聚合返回，咪咕支持翻页，我要下歌 / 布谷为单页
- ✅ 播放（在线音源直链）
- ✅ 歌词
- ✅ 排行榜 / 歌单：分组展示为「咪咕音乐 / 我要下歌 / 布谷音乐」三组

## 安装

在 MusicFree 中：

1. 「我的插件」→「添加插件」
2. 填入本插件地址：
   ```
   https://raw.githubusercontent.com/buaiwanyouxi/musicfree-all/main/all.js
   ```

## 关于「咪咕歌单」

咪咕**公开**接口中 `album` / `singer` / `playlist` / `radio` 等 bmw 接口均返回
`299997 请求不支持`（需登录态），故**公开无免 cookie 的歌单数据源**。

- **排行榜**：始终显示（免登录）。
- **歌单（个人 / 推荐歌单）**：需在插件「用户变量」中填入**咪咕登录 Cookie**
  （变量名 `miguCookie`）后才会显示并可播放；留空则仅显示排行榜。

> 搜索 / 播放 / 歌词 不受影响，无需任何登录。

## 已知限制

- 咪咕标清 `PQ` 为免费档；`HQ` / `SQ` 为会员专属（返回 `cannotCode 440013/440022`，插件会提示「会员专属」）。
- 我要下歌部分歌曲仅提供网盘（迅雷）下载、无在线播放源，此类会提示「暂无可在线播放的音源」。
- 我要下歌歌词取自详情页描述（纯文本，无逐行时间戳）。
- 播放直链含时效，已设 `cacheControl: no-store`。

## 目录

- `all.js` —— 合并插件主文件
- `test.cjs` —— 本地测试（注入 axios，咪咕走真实网络；xiage/buguyy 受沙箱 TLS 拦截，请参考 test-stub.cjs）
- `test-stub.cjs` —— 桩测试（mock axios，验证 xiage / buguyy 路由正确性，12/12 通过）

## 逆向来源

全部来自浏览器实测（Playwright 捕获真实请求 + axios 复现），无网络搜索 / 盲猜。
