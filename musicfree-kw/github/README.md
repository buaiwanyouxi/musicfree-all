# MusicFree 音源插件 - 酷我音乐

## 简介
酷我音乐音源（经 music.nxinxz.com 代理取链）。

## 安装方式
### 方式一：订阅源安装（推荐）
将以下 URL 添加到 MusicFree 订阅源：
https://raw.githubusercontent.com/buaiwanyouxi/musicfree-all/main/musicfree-kw/github/kw.js

### 方式二：本地安装
下载 `kw.js` 文件，在 MusicFree 中手动导入。
